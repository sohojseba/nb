# nb - সহজ সেবা | Sohoj Seba

> নরসিংদী ও কিশোরগঞ্জের স্থানীয় ডিজিটাল মার্কেটপ্লেস। পুরাতন পণ্য, বাসা ভাড়া, জমি-বাড়ি, ডাক্তার ও স্থানীয় সেবার ফ্রি বিজ্ঞাপন প্ল্যাটফর্ম।

### 🌟 আমাদের সম্পর্কে
সহজ সেবা হলো নরসিংদী ও কিশোরগঞ্জ জেলার মানুষের জন্য তৈরি একটি লোকাল মার্কেটপ্লেস। এখানে আপনি খুব সহজে আপনার এলাকার যেকোনো সেবা খুঁজে পাবেন এবং ফ্রিতে বিজ্ঞাপন দিতে পারবেন।

### ✨ ফিচার সমূহ
- 📦 **পুরাতন পণ্য:** মোবাইল, ফার্নিচার, বাইক সহ যেকোনো পুরাতন জিনিস ক্রয়-বিক্রয়
- 🏠 **বাসা ভাড়া:** এলাকাভিত্তিক বাসা, মেস, দোকান ভাড়ার বিজ্ঞাপন
- 🏡 **জমি-বাড়ি:** জমি, ফ্ল্যাট, বাড়ি ক্রয়-বিক্রয়
- 🩺 **ডাক্তার ও সেবা:** স্থানীয় ডাক্তার, মিস্ত্রি, টিউটর ও অন্যান্য সেবা
- 💬 **ফ্রি বিজ্ঞাপন:** সম্পূর্ণ ফ্রিতে পোস্ট করার সুবিধা

### 🛠️ Tech Stack
- Next.js 14
- Tailwind CSS
- MongoDB / Firebase

### 🚀 কিভাবে চালাবেন (Local Setup)
```bash
# 1. Clone করুন
git clone https://github.com/sohojseba/nb.git

# 2. ফোল্ডারে যান
cd nb

# 3. Package install করুন
npm install

# 4. Run করুন
npm run dev
